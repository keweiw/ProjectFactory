# M2 — History & Cumulative Report

**Status:** Complete locally
**Completed:** 2026-08-17

## What was built

- A History screen added as an independent M2 browser module, preserving the M1 game state machine.
- Lifetime hit rate, answer count, and current streak on the home screen.
- Cumulative hit-rate sparkline and overall report.
- Asset class, timeframe, and horizon breakdowns only after 20 records per group.
- Bullish-call bias and average response time only after 30 records.
- Local JSON export, validated JSON import, and confirmation-gated history clearing.

## Data and privacy

M2 reads only locally stored `SessionRecord` data plus public question metadata (`id`, asset class, timeframe, horizon) to group historical results. It never uses reveal-only fields for report grouping.
