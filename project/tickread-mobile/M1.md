# M1 — Mobile Web MVP

**Status:** Complete locally
**Completed:** 2026-08-16

## What was built

- Mobile-first static web app in `index.html`, `style.css`, and `src/app.ts`.
- Home screen with a lifetime hit-rate summary from `localStorage`.
- Ten-question rounds loaded from the M0 content package at `../tickread/code/data/`.
- Setup-only candlestick chart before an answer; upward swipe/button means bullish and downward swipe/button means bearish.
- Locked answer flow: future bars animate in, then the result shows correctness, move, ticker, timeframe, date range, and response time.
- Next-question control is enabled after the required 2.2-second reveal period.
- Round report includes hit rate, longest streak, and all ten outcomes.

## Contract and privacy behaviour

The question screen reads only public metadata and setup bars before the user submits a direction. It reads answer and reveal fields only inside the locked answer/reveal flow. Each submitted response is stored locally as a `SessionRecord`-compatible object.

## Run locally

```powershell
Push-Location project/tickread/code
pnpm exec tsc -p ../tickread-mobile/tsconfig.json
Pop-Location

# Serve the repository over HTTP, then open /project/tickread-mobile/
```

The app requires HTTP hosting because browsers do not allow question-bank `fetch` requests from `file://` pages.
