# M3 — PWA Polish & Offline

**Status:** In progress
**Started:** 2026-08-19

## Scope

- Installable web-app manifest and standalone presentation.
- Offline app-shell and question-bank cache using a Service Worker scoped to `project/`, allowing it to cache both the mobile client and its shared question bank.
- Background question-bank refresh. A newly installed worker is activated only before a new round begins; a round already in progress continues with its loaded in-memory deck.
- Vibration feedback for answer lock and reveal, suppressed whenever reduced motion is requested.
- System light/dark colour support plus a persisted manual toggle, 52 px minimum controls, and the existing text-and-arrow answer labels.

## Deliberate boundary

The question bank remains downloaded and cached on first successful load rather than copied into the mobile directory. This keeps one shared authoritative bank while allowing the Service Worker at `project/sw.js` to cache it within its valid scope.

## Verification target

- TypeScript compiles in strict mode.
- First successful load populates the app-shell and question-bank caches.
- With DevTools Offline enabled after that load, a full round can start and complete.
- A waiting service worker activates only when the user begins the next round.
